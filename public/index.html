No Gemini API key set
You're chatting without a Gemini API key. You can enter one now, or use Auralis's local model — it needs no key and no account. The server's local model answers right away; downloading the browser model makes it run on your device.
Analyze images?
Analyzing attached images needs a vision engine. Download the local Vision model (LFM 2.5 VL, ~770 MB one-time — it then runs fully on your device), or save a free Gemini API key to analyze images instantly with no download.
