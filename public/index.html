Downloaded models run 100% on your device and are cached by the browser. Nothing downloads until you ask.

Gemini API key
Optional. With a key saved, Auralis synthesizes answers with Gemini; without one, the local model handles everything — no key required. The key is stored only in this browser and is sent only to your own Auralis server.
Get a free key at aistudio.google.com/app/apikey.
No Gemini API key set
You're chatting without a Gemini API key. You can enter one now, or use Auralis's local model — it needs no key and no account. The server's local model answers right away; downloading the browser model makes it run on your device.
